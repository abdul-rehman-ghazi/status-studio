# M5 — Render Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Export produces a real MP4: trimmed, framed (preset or free crop, crop or blur), with the caption (original, Roman Urdu or English) and branding burned in, matching the Style preview.

**Architecture:**
- The bundled FFmpeg can't encode H.264 (spec §10 Q1), so the final render uses **Android's Media3 Transformer** through a small Kotlin platform channel, with hardware H.264/AAC.
- Pure Dart builders decide everything the renderer needs: crop rectangle, normalised crop, the render spec map and the overlay layout.
- Flutter paints caption + branding onto one transparent PNG at output size, and Media3 overlays it.
- The Dart `Media3Renderer` implements M1's `Renderer`.

**Tech Stack:** androidx.media3 1.11.1 (`media3-transformer`, `media3-effect`, `media3-common`), Kotlin, Flutter platform channels, dart:ui (`PictureRecorder`), google_mlkit_translation.

**Spec:** FR-6, FR-7, FR-8, FR-9, FR-15 (`ClipSource`), §5, §6.3, §6.3.1, §6.5, §6.6, §7, §10 Q1.

**Builds on M2b:** the render input is `ClipSource { file, offset, window }`. Clip times sent to Media3 are relative to `offset`.

## Global Constraints

- M1–M4 and M2b Global Constraints apply.
- Output MP4: H.264 (`video/avc`) + AAC (`audio/mp4a-latm`), source frame rate, sizes from `outputSizeFor` (M1).
- Crop sizes are even integers (rounded down); offsets are rounded down to whole pixels. Media3 receives the crop as normalised device coordinates (spec §6.3.1).
- The overlay PNG is exactly the output size, transparent, applied last.
- Caption and branding geometry exactly as FR-7/FR-8.
- The preview (`ReelPreview`) and the export use the same `cropRectFor` and `layoutOverlay`.
- Only `android/app/src/main/kotlin/com/hotmail/arehmananis/statusstudio/render/` imports Media3. Channel names: `status_studio/render` (methods `start`, `cancel`) and `status_studio/render/events`.
- FFmpeg is not used for the final render.

## Review Focus

- **Free crop from a source whose size isn't 1920×1080** (e.g. 1280×720 or vertical 720×1280) crops the right region. Test: Task 1 `free_crop_uses_source_pixels_for_720p`.
- **A clip file whose zero isn't video time zero** (M2b offset) trims at the right moment. Test: Task 2 `clip_times_are_relative_to_source_offset`.
- **A very long caption** shrinks, then ellipsizes, and never overflows the frame. Test: Task 4 `long_caption_shrinks_then_clips`.
- **Cancelling an export** stops Media3 and deletes the partial MP4. Test: Task 5 `cancel_invokes_native_cancel_and_deletes_partial`.
- **A native render error** surfaces as "Couldn't make the reel." rather than a hang. Test: Task 5 `native_error_surfaces_render_exception`.

### Task 3: Kotlin Media3 renderer

**Files:**

- Modify `MainActivity.kt` (register `RenderChannel` in `configureFlutterEngine`)
- Test `android/app/src/test/kotlin/com/hotmail/arehmananis/statusstudio/render/RenderSpecTest.kt`

**Interfaces:**
- `data class RenderSpec(...)` mirrors Task 2's keys. `companion object { fun fromMap(map: Map<String, Any?>): RenderSpec }` throws `IllegalArgumentException` on a missing or wrong-typed key.
- `class ReelRenderer(context: Context)` with `fun start(spec: RenderSpec, listener: Listener)` and `fun cancel()`.
  - Media item: `MediaItem.fromUri(spec.inputPath)` with `ClippingConfiguration` (start/end ms).
  - Effects, in order:
    - **crop:** `Crop(l, r, b, t)`, then `Presentation.createForWidthAndHeight(w, h, Presentation.LAYOUT_SCALE_TO_FIT)`.
    - **blur:** `GaussianBlurWithFrameOverlaid(sigma, sharpScaleX, sharpScaleY)` on the source frame, then `Presentation.createForWidthAndHeight(w, h, LAYOUT_SCALE_TO_FIT)`. The effect draws the whole input frame sharp, so it can't come after a covering `Presentation` (spec §6.3.1). Dart sends `sharpScaleX`/`sharpScaleY` (Task 2 gained these two keys).
    - **none:** `Presentation` only.
    - Always last: `OverlayEffect(ImmutableList.of(BitmapOverlay.createStaticBitmapOverlay(bitmap)))`.
  - The `Transformer` uses `setVideoMimeType` and `setAudioMimeType` from the spec.
  - Progress: poll `transformer.getProgress(ProgressHolder)` every 250 ms on the main looper.
  - `cancel()` calls `transformer.cancel()` and deletes `outputPath`.
- `RenderChannel` sends events `{ "type": "progress", "value": 0.0–1.0 }`, `{ "type": "done", "path": … }` and `{ "type": "error", "message": … }`. Only one render runs at a time; `start` while busy returns a `busy` error.

### Task 5: Dart Media3 renderer

**Files:** Create `lib/src/features/export/application/media3_renderer.dart`; Modify `renderer.dart` (provider → `Media3Renderer`); Test `test/src/features/export/application/media3_renderer_test.dart`

**Interfaces:**
- `Media3Renderer(RenderServices services)` implements `Renderer`. `RenderServices { Future<ClipSource> Function(ReelDraft) clipSourceFor; MediaProbe probe; Future<Uint8List> Function(OverlaySpec) paintOverlay; Future<Directory> outputDirectory; }` is one value object (four dependencies; CLAUDE.md allows three parameters). `MediaProbe.videoSize` (FFprobe) gives the clip file's frame size, which crops and the free size are measured in.
  - `render` is built on a `StreamController`, not `async*`: cancelling an `async*` stream waits for the generator, which hangs while the native render runs.
  - Export shows "Couldn't make the reel." with Retry and Back when the render fails (spec §8); a full disk keeps "Not enough space on your phone.".
  - `render(draft)` writes the overlay PNG to the temp dir and builds a `RenderJob` → `renderSpecFor`.
  - It invokes `start`, then maps events to `RenderRunning(value)` and `RenderFinished(path)`.
  - An `error` event (or a `PlatformException`) is thrown as `RenderFailedException`.
  - `cancel()` invokes `cancel`.
