# M5 — Render Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Export produces a real MP4: trimmed, framed (preset or free crop, crop or blur), with the caption (original, Roman Urdu or English) and branding burned in, matching the Style preview.

**Architecture:**
- Pure builders decide everything FFmpeg needs: crop rectangle, filter graph and arguments. A pure layout decides where caption and branding go.
- Flutter paints caption + branding onto one transparent PNG at output size.
- `FfmpegRenderer` runs one pass with `FfmpegRunner` (M2) and reports progress from FFmpeg statistics.

**Tech Stack:** ffmpeg_kit_flutter_new_min 2, dart:ui (`PictureRecorder`), google_mlkit_translation.

**Spec:** FR-6, FR-7, FR-8, FR-9, §6.3, §6.5, §6.6, §7, §10 Q1.

## Global Constraints

- M1–M4 Global Constraints apply.
- Output MP4: H.264 + AAC 128 kb/s, `-movflags +faststart`, source frame rate, sizes from `outputSizeFor` (M1).
- Crop and scale **sizes** are even integers (rounded down); crop **offsets** are rounded down to whole pixels.
- Caption and branding geometry exactly as FR-7/FR-8 (fractions of output width/height).
- The preview (`ReelPreview`) and the export use the same `cropRectFor` and `layoutOverlay` functions, so they can't drift apart.

## Review Focus

- **Free crop from a source whose size isn't 1920×1080** (e.g. 1280×720 or vertical 720×1280) must crop the right region. Test: Task 2 `free_crop_uses_source_pixels_for_720p`.
- **A very long caption** must shrink, then ellipsize, never overflow the frame. Test: Task 4 `long_caption_shrinks_then_clips`.
- **Cancelling an export** must delete the partial MP4. Test: Task 6 `cancel_deletes_partial_output`.
- **A video without an audio stream** must still export (`-map 0:a?`). Test: Task 3 `audio_map_is_optional`.
- **Roman variant for non-Urdu transcripts** must not be offered. Test: Task 7 `roman_hidden_for_non_urdu`.

**Interfaces:**
- `String romanizeUrdu(String text)`

  - Keeps punctuation and newlines; converts `۔` to `.`.
- `abstract interface class CaptionTranslator { bool supports(String languageCode); Future<String> toEnglish(String text, String languageCode); }`
  - `MlKitCaptionTranslator` maps codes with `TranslateLanguage` and downloads the pack on demand.
  - It throws `TranslationPackMissingException` when offline without the pack, and closes the translator after use.
