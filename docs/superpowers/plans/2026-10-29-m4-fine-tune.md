# M4 — Fine-tune Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fine-tune shows a real waveform around the clip, plays the clip, warns about long clips, and changing the language on Script re-runs the script without downloading again.

**Architecture:**
- The waveform comes from the **clip file** (M2b `ClipSource`). It always exists, even when the script came from captions and no full audio was downloaded.
- It's converted once to a 16 kHz mono WAV with FFmpeg, then peaks are computed in a background isolate (`Isolate.run`) and drawn with a `CustomPainter`.
- The visible range is M2b's `ClipWindow`.

**Tech Stack:** Flutter, dart:isolate.

**Spec:** FR-2 (language change), FR-5, FR-15, §10 Q3.

**Builds on M2b:** `ClipWindow`/`clipWindowFor` (window maths and its tests live there), `ClipSource { file, offset, window }`.

## Global Constraints

- M1–M3 Global Constraints apply.
- Visible range = the `ClipSource.window`. 60 bars.
- Long-clip warning above 60 s: "Longer than 60 s. WhatsApp Status may cut it." (a warning, never a block).
- Peak computation never runs on the UI isolate.

## Review Focus

- **A clip window that starts after time 0** (offset > 0) maps WAV samples to video time correctly. Test: Task 1 `peaks_use_source_offset`.
- **A WAV shorter than the bucket count** (very short audio) must not divide by zero. Test: Task 1 `short_audio_yields_requested_bucket_count`.
- **Re-running the script in another language** must not download the script audio again. Test: Task 3 `language_rerun_reuses_cached_audio`.
- **A clip exactly 60.0 s** must not warn; 60.5 s must. Test: Task 2 `warns_only_above_sixty_seconds`.
- **A silent WAV** draws flat bars, not NaN. Test: Task 1 `silent_audio_yields_zero_peaks`.

### Task 1: Waveform maths

**Files:** Create `lib/src/features/clip/domain/waveform.dart`; Test `test/src/features/clip/domain/waveform_test.dart`

**Interfaces:**
- `class WaveformRequest { const WaveformRequest({required String wavPath, required Duration offset, required ClipWindow window}); }`, with value equality.
- `List<double> waveformPeaks(Uint8List wavBytes, WaveformRequest request, {required int buckets})`
  - The WAV's time zero is `request.offset` in video time.
  - Reads 16 kHz mono PCM16 from the WAV's `data` chunk. FFmpeg adds a `LIST` chunk before it, so the header isn't always 44 bytes.
  - Returns the max absolute amplitude per bucket, normalised to 0–1 by the loudest bucket, or all zeros for silence.
