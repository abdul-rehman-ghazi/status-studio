# M4 — Fine-tune Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fine-tune shows a real waveform around the clip, plays the clip, warns about long clips, and changing the language on Script re-runs the script without downloading again.

**Architecture:** Waveform peaks are computed from M3's `audio.wav` in a background isolate (`Isolate.run`) and drawn with a `CustomPainter`. A pure `WaveformWindow` decides the visible time range.

**Tech Stack:** Flutter, dart:isolate.

**Spec:** FR-2 (language change), FR-5, §10 Q3.

## Global Constraints

- M1–M3 Global Constraints apply.
- Visible window: from 5 s before the clip start to max(clip end + 5 s, start + 30 s), clamped to the video. 60 bars.
- Long-clip warning above 60 s: "Longer than 60 s. WhatsApp Status may cut it." (a warning, never a block).
- Peak computation never runs on the UI isolate.

## Review Focus

- **A clip near the start or end of the video** must not produce a window outside the video. Tests: Task 1 `window_clamped_at_video_start`, `window_clamped_at_video_end`.
- **A WAV shorter than the bucket count** (very short audio) must not divide by zero. Test: Task 1 `short_audio_yields_requested_bucket_count`.
- **Re-running the script in another language** must not download the audio again. Test: Task 3 `language_rerun_reuses_cached_audio`.
- **A clip exactly 60.0 s** must not warn; 60.5 s must. Test: Task 2 `warns_only_above_sixty_seconds`.
- **A silent WAV** draws flat bars, not NaN. Test: Task 1 `silent_audio_yields_zero_peaks`.

### Task 1: Waveform maths

**Files:** Create `lib/src/features/clip/domain/waveform.dart`; Test `test/src/features/clip/domain/waveform_test.dart`

**Interfaces:**
- `class WaveformWindow { const WaveformWindow({required Duration start, required Duration end}); }`
- `WaveformWindow waveformWindowFor(ClipRange clip, Duration videoDuration)`
- `List<double> waveformPeaks(Uint8List wavBytes, {required Duration from, required Duration to, required int buckets})`
  - Reads 16 kHz mono PCM16 after the 44-byte header.
  - Returns the max absolute amplitude per bucket, normalised to 0–1 by the loudest bucket, or all zeros for silence.
