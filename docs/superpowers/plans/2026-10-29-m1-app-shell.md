# M1 — App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every screen of the flow (Home → Source → Processing → Script → Fine-tune → Style → Export → Done) works end to end with fake services, and all pure domain logic is real and tested.

**Architecture:** One immutable `ReelDraft` in a Riverpod `Notifier` carries the reel through the flow. Screens read and update it. Services (`VideoSource`, `ScriptPipeline`, `Renderer`) are interfaces with fake implementations bound through providers; M2–M5 swap in real ones.

**Tech Stack:** Flutter 3.47.8 (FVM), flutter_riverpod 3, go_router 18.

**Spec:** `docs/superpowers/specs/2026-10-29-status-studio-design.md`

## Global Constraints

- Run everything through FVM: `fvm flutter test`, `fvm flutter analyze` (must print "No issues found!"), `fvm dart format lib test`.
- Imports are `package:status_studio/...`.
- No code generation (no freezed, no riverpod_generator). Write `copyWith`, `==` and `hashCode` by hand.
- Colours and font names only from `lib/src/theme/app_theme.dart` (`AppColors`, `AppFonts`).
- Copy is literal from the spec and the design canvas. The app is general-purpose: never mention a content type (naat, bayan, …) in UI or code.
- Code style and test style per `CLAUDE.md`. Test names are snake_case behaviour sentences.
- Clip minimum 3 s; nudge step 0.5 s. Output sizes and the free-crop default/minimum are as in spec FR-6.

## Review Focus

- **A link pasted with whitespace, `si=` share params or `m.` host** must parse. Tests: Task 2 `parses_mobile_link_with_share_params`, `parses_link_with_surrounding_whitespace`.
- **A tap on an earlier line after a start was chosen** must restart the selection, not create a reversed range. Test: Task 1 `tap_before_start_restarts_selection`.
- **A nudge past the video's end or start** must be ignored, not clamp to a sub-3-second clip. Tests: Task 1 `nudge_end_past_video_end_is_ignored`, `nudge_start_below_zero_is_ignored`.
- **A free-crop drag past the frame edge** must keep the rectangle inside. Test: Task 3 `move_clamps_rectangle_inside_frame`.
- **Changing the transcript (language re-run)** must clear the old selection and clip. Test: Task 4 `set_transcript_clears_selection_and_clip`.
